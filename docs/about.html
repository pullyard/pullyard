About PullYard

PullYard is a free, open-source desktop app for reviewing, fixing and merging pull requests, with native builds for macOS, Windows and Linux. It is an independent project maintained in the open on GitHub.

What PullYard is

PullYard is a free, MIT-licensed desktop app for pull requests. It shows your review requests and your own pull requests in one list, opens big diffs in a native viewer, and lets you comment, approve, request changes and merge without a browser tab. A built-in agent workspace runs the Claude Code CLI, so review feedback can go to an AI agent with one click.

It is three native apps, not one web app in a wrapper: SwiftUI on macOS 14 and later, WinUI 3 on Windows 10 and 11, GTK 4 and libadwaita on Linux. GitHub and GitHub Enterprise Server get every feature. GitLab, Bitbucket Cloud and Gitea or Forgejo show your review requests and your own pull or merge requests on macOS.

Who makes it

PullYard was started and is maintained by @Vaache. The source code, the issue tracker and every release live in the open at github.com/pullyard/pullyard.

The project is independent. It is not affiliated with GitHub, Inc. or Anthropic; it uses the public GitHub API and runs the official Claude Code CLI that you install yourself.

Why it exists

Reviewing code in a browser tab is slow on big diffs, and the fix for a review comment usually happens somewhere else. PullYard keeps the whole loop in one native window: read the diff, leave the review, hand the feedback to an agent, re-request review, merge.

It only does the review side. PullYard does not stage, commit or push, so it sits next to your git client or the command line.

Questions

Who makes PullYard?

PullYard is an independent open-source project started and maintained by @Vaache, with contributions through GitHub. It is not made by GitHub, Inc. or Anthropic.

Is PullYard free?

Yes. PullYard is free and open source under the MIT license, with no paid tier and no account. There is an optional "Buy me a pizza" donation.

Was PullYard called something else before?

Yes. The app was named Shipyard until version 2.6.0 (October 15, 2026), when it became PullYard and gained Windows and Linux builds.

How do I report a bug or ask for a feature?

Open an issue on GitHub. For a security problem, please don't post the details in a public issue: open an issue that only asks for a private channel and the maintainer will follow up.
