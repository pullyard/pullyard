PullYard / About

A small app for a daily chore.

PullYard is a free, open-source desktop app for reviewing, fixing and merging pull requests. It runs natively on macOS, Windows and Linux, and it's built in the open by one developer and whoever feels like helping.

Why I built it

I review pull requests every day, and for years that meant a pile of github.com tabs. A big diff would make the fan spin. I'd lose my place when the page reloaded. And when a reviewer asked for a change, I'd copy the comment into my editor, fix it, push, and go back to find the thread again.

So I wrote the app I wanted. PullYard puts review requests and my own PRs in one list, opens large diffs without stutter, and lets me comment, approve and merge from the keyboard. When there's feedback to fix, one click hands it to Claude Code, right next to the diff.

It does one job. PullYard doesn't stage, commit or push, so it sits beside your git client or terminal and stays out of the way.

It's three real native apps: SwiftUI on macOS, WinUI 3 on Windows, GTK 4 and libadwaita on Linux. That's more work than one web app in a wrapper, and it's the reason the app starts fast and stays light.

Questions

Who makes PullYard?

One developer, @Vaache, plus anyone who sends a pull request. It's an independent open-source project, not a GitHub or Anthropic product.

Is it really free?

Yes. MIT license, no paid tier, no account, no trial that runs out. If it saves you time you can buy me a pizza, and that's the whole business model.

Wasn't this called Shipyard?

It was. The app shipped as Shipyard until version 2.6.0 on October 15, 2026. That release added Windows and Linux, and the name changed to PullYard with it.

How do I report a bug or ask for something?

Open an issue on GitHub. If it's a security problem, don't post the details in public: open an issue that just asks for a private channel and I'll get back to you.
