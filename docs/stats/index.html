    Connections

    Downloads and stars work without anything. Connections unlock the rest. Keys and links are saved only in this browser.

    GitHub

    Unlocks repo visitors, clones, referring sites and stargazers.

    How to create the token
    1. Open new fine-grained token.
    2. Resource owner pullyard, repository access Only select repositories → pullyard.
    3. Repository permissions: Administration → Read-only. Nothing else.

    Umami

    Unlocks website visitors, channels, countries and download clicks.

    Umami Pro: use an API key instead

    Where to find the share link
    1. Umami → Settings → Websites → pullyard.github.io → Share.
    2. Turn on Overview and Events, save, copy the link.
    3. Anyone with the link can see the stats, so keep it private.
