PullYard / PR review apps with Claude Code

Desktop apps that send PR review comments to Claude Code

PullYard is a free desktop app for macOS, Windows and Linux where you review a pull request, leave inline comments and send them to Claude Code to fix. Diffity, Reviu and PR Cockpit work on the same idea from different angles. Here's how the four compare.

Four apps, four takes on the same idea

All four put a coding agent next to code review. They differ in where they start: the pull request, the diff, the agent or the queue.

PullYard

The whole pull request, start to merge

A native review app for GitHub, GitLab and Bitbucket. Read the diff, comment, approve and merge. Fix with agent hands the review comments to Claude Code in an isolated git worktree, and Reply and resolve closes the fixed threads after the push.

Good fit: teams on mixed desktops who want review, fixes and merge in one free app.

Diffity

A diff viewer built around Claude Code

A macOS app with a GitHub-style diff view. You annotate lines as you read, send the comments to Claude Code, and submit the review to GitHub as a comment, approval or change request.

Good fit: Mac users who want a focused diff-and-comment tool for one pull request at a time.

Reviu

Review what your agent just wrote

A native desktop app that launches the agent CLI you already use, shows each diff locally and sends your line comments back to the agent. GitHub pull request review, checks and merge are in the Pro tier.

Good fit: people who mostly review their own agent's local changes before opening a pull request.

PR Cockpit

A very fast review queue

A keyboard-first app for macOS and Linux that keeps your pull requests, diffs, threads and checks in a local cache so they open instantly. It can hand the pull request you're on to your coding agent.

Good fit: reviewers with a long queue who care most about speed and the keyboard.

How to choose

You review other people's pull requests all day. Pick the app built around the pull request: PullYard, or PR Cockpit if raw speed on macOS or Linux is what you're after.

You mostly check what your own agent wrote before pushing. Reviu starts from the agent session, which suits that better.

You want one diff, your comments, and Claude Code. Diffity keeps it that simple on a Mac.

You want review, fixes and merge in one place, on any desktop, for free. That's what PullYard is for. It also handles GitLab and Bitbucket, stacked pull requests and failing CI. See the Fix with agent guide for the loop step by step.

Questions

Is there a desktop app that sends PR review comments to Claude Code?

Yes, several. PullYard, Diffity, Reviu and PR Cockpit all connect pull request review to a coding agent. PullYard is the one that covers the whole loop in a free app on macOS, Windows and Linux: review the pull request, send the comments to Claude Code with Fix with agent, push, resolve the threads and merge.

Which of these apps are free?

PullYard is free and MIT-licensed with no paid tier. Diffity is free and open source. PR Cockpit publishes its source on GitHub. Reviu has a free app for local review, and its GitHub pull request features are in the paid Pro tier.

Which ones run on Windows?

PullYard has a native Windows app (WinUI 3) alongside macOS and Linux. Diffity is a macOS app, and PR Cockpit lists macOS and Linux. Check Reviu's site for its current platforms.

Do I need a Claude subscription for PullYard?

You need the Claude Code CLI installed and signed in with your own account. PullYard runs that CLI; it doesn't resell it. Agent accounts can also use OpenRouter or another Anthropic-compatible endpoint.
