PullYard / Stacked pull requests

A desktop app for stacked pull requests

PullYard is a free, native desktop app that shows your stacked pull requests as a tree, with the status of every one, and lets you review and merge them in order. It works with any stack on GitHub, however you made it.

What a stack looks like in PullYard

Stacking keeps reviews small. The hard part is seeing the stack. That's the part PullYard does.

A stack is a chain of pull requests where each one builds on the one below: main ← #1 ← #2 ← #3. On github.com you see them one at a time and keep the order in your head. PullYard draws the whole thing.

  • In the PR header: where this pull request sits in its stack, and what it's stacked on.
  • A Stack tab: the full stack as an indented list, or as a graph from the base branch down, side branches included.
  • On every card: branch, base, status (ready, in review, checks running, CI failed, changes requested, draft), the last commit and the Jira key from the branch name.
  • In the sidebar: every stack your open pull requests belong to, across repositories.
  • Notes: pin a note, question or decision to any card. Notes stay on your computer.

Reviewing a stack, start to finish

The order matters in a stack. This is the order that works.

  1. Open the stack. Pick it in the sidebar, or open any pull request in it and switch to the Stack tab.
  2. Start at the bottom. Click the first card. You get that pull request's diff only, not the whole stack's.
  3. Review and move up. Comment, approve or request changes, then click the next card.
  4. Fix what comes back. If you're the author, Fix with agent sends the review comments on that pull request to Claude Code.
  5. Merge from the bottom. The status on each card shows which pull requests are ready and which are still waiting on checks or review.

Questions

What is a stacked pull request?

A stacked pull request is a pull request whose base is another pull request's branch instead of main. A stack is a chain of them, each building on the one below, so a large change can be reviewed in small pieces.

Does PullYard create or restack branches?

No. PullYard reads and reviews stacks; it doesn't change your branches. Create the stack with git, the GitHub CLI, Graphite or GitButler, and PullYard picks it up from the base branches of your open pull requests.

Do I need Graphite or another service for PullYard to see my stack?

No. PullYard works out the stack from the pull requests themselves, so any stack on GitHub shows up, however it was made.

Which platforms have the stack view?

macOS, Windows and Linux. The stack view came to macOS first and to Windows and Linux in the next release.
