Fix review comments with Claude Code

When a reviewer asks for changes, PullYard can hand the comments to Claude Code with one click. The agent makes the edits in a separate worktree, you read them, push, and resolve the threads. Here's the whole loop.

Download PullYard See screenshots

What you need

PullYard

Any current version, on macOS, Windows or Linux. Install it here.

Claude Code CLI

Installed and signed in with your own account. PullYard runs the CLI; it doesn't ship one.

The repository on your computer

The agent edits a local copy, so it needs the project cloned.

Step by step

Six steps, and the first two are clicks.

  1. Open the pull requestFind it in your list and open it. The review threads sit next to the diff, same as on GitHub.
  2. Click Fix with agentPullYard starts a new Claude Code session and gives it the review feedback. If the reviewer left a "Fix prompt", PullYard uses that. If not, it writes the prompt from the comments.
  3. Let it work, and watchThe agent works in an isolated git worktree, so your own checkout isn't touched. You approve tool calls in the chat and see a diff for every edit.
  4. Read what changedGo through the edits the way you'd read a colleague's. Ask for changes in the same chat if something's off.
  5. Commit and pushUse Commit and push with agent. The new commits land on the pull request's branch.
  6. Close the loopReply and resolve answers the fixed threads and closes them in one go. Then re-request review with one click.

Why not just paste the comments into a terminal?

You can, and for one comment it's fine. It gets old at ten. You copy each comment, explain which file it was on, switch windows, fix, push, then go back and hunt for the threads to resolve.

Fix with agent skips the copying. The agent gets every comment with its file and line, works in a separate worktree so your branch stays clean, and when it's pushed PullYard knows which threads were fixed.

You're still the reviewer of the fix. Nothing is committed or pushed until you say so.

Questions

Does Fix with agent run without asking me?

No. It opens a session with a prompt, and you stay in the chat: you approve tool calls, see each edit as a diff, and decide when to commit and push.

Do I need a paid Claude plan?

You need whatever the Claude Code CLI needs: your own Claude account, signed in on your computer. PullYard is free and doesn't add a charge. From version 2.14.0 an agent account can also use OpenRouter or another Anthropic-compatible endpoint.

Is my code sent to PullYard?

No. PullYard has no backend. The agent is the Claude Code CLI running on your computer under your own account.

What's a Fix prompt?

A note a reviewer can leave that says exactly what to change. When one is there, PullYard hands it to the agent as written instead of writing its own from the comments.
