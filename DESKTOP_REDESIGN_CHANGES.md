# PullYard Desktop (macOS) — что изменилось в фазах 1 и 2

Фаза 1 закоммичена (`e9eb459`), фаза 2 пока не закоммичена. Каждый пункт ниже: что поменялось и где смотреть при тестировании.

Тестовая сборка: `build/ux-overhaul/PullYard UX Test.app` (release, отдельный bundle id `dev.vaache.shipyard.uxtest`, ваши настройки основной версии не трогает).

## Фаза 1

### Тулбар и заголовок окна
- **Одна кнопка обновления на окно.** Показывает «2m ago», во время обновления — рисующийся логотип. Двойного ↻ при открытом PR или issue больше нет.
  - Через 5 минут без обновления подпись янтарная.
  - Ошибки названы конкретно: «Offline», «Rate-limited until 14:02», «Sign in again», «Couldn't refresh».
  - Клик обновляет текущий PR, ⌘R — всё.
- **Заголовок окна показывает открытый PR, issue, репозиторий, проект, коммит** (и элемент GitLab/Gitea), а не название списка.
- **Кнопка Merge в тулбаре:** приглушена, если слиянию что-то мешает, и подсказка называет причину; зелёная, когда всё готово.

### Загрузка
- **Все спиннеры (25 штук) заменены логотипом, который рисует сам себя** (`PYLoader`). Он рисуется на Core Animation, поэтому почти не нагружает CPU.
- Полоса загрузки списка стала бегущей «волной».

### Статусы
- **Чипы вместо голых иконок:** «Failing», «Running», «Passing», «Approved», «Changes requested».
- Сводка проверок «1 failing · 4 passing» вместо «✕1 ✓0», у вкладки Checks бейдж «1 failing».
- Значки состояния PR без двойного кольца: простые pencil / xmark / checkmark.

### Пустая правая панель
- Рисующийся логотип, волны, мягкий фон, заголовок с засечками «Nothing open yet», подсказки ⌘L / ⌘K / ⌘/.

### Diff
- Коралловый «+» для комментария появляется только при наведении на номер строки.
- Цветная полоса 3 pt слева у добавленных и удалённых строк.
- Номера строк контрастнее.
- Навигация подписана словами: «File ↑↓», «Change ↑↓», «Comment ↑↓»; панель высотой 28 pt.

### Шит Review
- Вердикт выбирается сегментами Comment / Approve / Request changes.
- Кнопка отправки меняет текст и цвет: «Approve» зелёная, «Request changes» красная, «Comment» синяя.
- Если отправить нельзя, причина написана под полем.
- Видны неотправленные inline-комментарии (файл:строка и текст).
- Если PR ваш, выбора вердикта нет: остаётся только комментарий.

### Цвета и motion
- Новые токены: `syLink`, `syCoralInk`, `syCoralFill`, `syOnCoral`, `syAmberInk`, `syHarborLine`, `syWake`.
- Контрастнее `syDim`, `syGutter`, линии.
- Залитые коралловые кнопки («Fix with agent») стали чуть темнее, чтобы белый текст читался.
- Сегмент «Open/Closed/All» на тёмно-синей заливке.
- Строки списка въезжают на 8 pt вместо 60, каскад максимум на 8 строк.
- Одна кривая анимации для логотипа везде.

### Прочее
- Settings: синий акцент, блок About с логотипом и версией (вкладка Advanced).
- Кнопка обновления во вкладке Jira и в просмотре кода репозитория.
- Переименования «Claude Code» → «Agents» / «agent session» в названиях функций. Упоминания самого инструмента (вход, «Runs Claude Code») оставлены.

## Фаза 2

### Завершение действий (тосты)
- **Тосты на стекле с кнопкой действия**, живут 5 с, если есть действие.
- После merge: кораблик «отплывает», тост «Merged #45 into main» и кнопка **«Restore branch»**, если ветка удалялась (восстанавливает её на том же коммите), иначе — «Next review →».
- После approve: печать ✓ и «Next review →».
- После «Request changes» и обычного ревью — короткий тост.

### Шит Merge
- **Живой чек-лист требований** прямо в шите, обновляется сам.
- Главная кнопка зависит от состояния:

| Состояние | Главная кнопка | Вторая |
|---|---|---|
| Всё готово | Merge (зелёная, Enter) | Merge when ready, если доступно |
| Ждём проверки/ревью | Merge when ready (auto-merge) | Merge anyway |
| Конфликты | Resolve with agent… | Merge anyway |
| Ветка отстаёт | Update branch | Merge anyway |
| Другое блокирует | Merge anyway (красная обводка) | Merge when ready |

- Метод слияния — сегменты с иконками (показываются, только если методов больше одного).

### Требования к merge в заголовке PR
- В строке конфликтов — **«Resolve with agent»**, в строке упавших проверок — **«Fix with agent»**.
- «Update branch» и «Ready for review» живут в своих строках; в заголовке они видны, только когда список требований свёрнут.
- **«View conflicts» открывает popover** со списком файлов, «Show in conversation» и «Resolve with agent…».
- Баннеры CI и конфликтов не объединены (вопрос к владельцу).

### Свёрнутая плашка PR
- На вкладках Files, Checks, Commits полный заголовок сворачивается в строку 36 pt: состояние, #N, название, чипы «1 failing», «Conflicts», «Viewed x/y», чип агента.
- Шеврон ▾ раскрывает полный заголовок, ▴ сворачивает обратно.

### Меню «Pull Request» и палитра
- **Новое меню «Pull Request»** в строке меню:
  - Write Review… ⇧⌘R
  - Approve ⇧⌘A
  - Request Changes…
  - Merge… ⇧⌘M
  - Fix with Agent ▸ Review Comments (⇧⌘F) / Failing Checks
  - Re-run Failed Checks
  - Mark All Files Viewed
  - Open in Browser ⇧⌘O
  - Copy Link
  - Copy Checkout Command
  - Next / Previous in Queue ⌥⌘↓ / ⌥⌘↑
- Невидимые кнопки-шорткаты в PR убраны, их заменило меню.
- **Палитра (⌘K):** сверху секция «This pull request» с теми же действиями; на macOS 26 — стеклянная.
- В меню добавлены стандартные команды сайдбара.

### Список PR
- **Плотность строк: Compact / Standard / Roomy** — в меню сортировки над списком и в Settings → General. По умолчанию Roomy (как было).
- **j / k** — следующий / предыдущий PR в списке.
- У сортировки подпись «Updated» вместо голой иконки.

### Файлы в PR
- Панель файлов меняет ширину перетаскиванием (200–420), двойной клик сбрасывает.
- Кнопка «по папкам / плоский список» (⌥T).
- Коралловая полоса прогресса «x/y viewed».
- Чип **«Mine N»**: только файлы, где вы владелец по CODEOWNERS.
- У каждого непросмотренного файла +/−.
- Новые установки открывают diff без переноса строк; у вас настройка сохранена.

### Уведомления
- Галочка **Done при наведении** на строку и клавиша **E**.
- Done отправляется через 5 с, в тосте есть **Undo**.

### Пустая правая панель
- Карточки **«Your turn» / «Needs attention» / «Recent»** под логотипом.
- **Чек-лист первого запуска:** уведомления, подключить Agents, Jira (можно скрыть ✕).
- Клик по сплэшу при запуске сразу пропускает его.

### Агент рядом с PR
- В заголовке PR чип **«Agent running · 2m»** / «Agent needs you», если из этого PR запускали агента. Клик открывает сессию.

### Стекло и доступность
- Liquid Glass (macOS 26) на плавающих элементах: тосты, палитра, капсула pull-to-refresh, капсулы offline/rate-limit/буфера, подсказки тура, оверлей перетаскивания в чате. На macOS 14/15 — прежний материал.
- **Reduce Transparency** делает их непрозрачными.
- **Increase Contrast:** линии вдвое плотнее, второстепенный текст и номера строк темнее, у чипов обводка.

### Сайдбар
- В узком режиме (окно уже 1180) вместо линий-разделителей подписи групп: INBOX, PR, ISS, CODE, AI.
- Плитки иконок масштабируются вместе с размером текста (⌘+ / ⌘−).

### Спайк
- Флаг `ui.glassToolbar` (выключен): тулбар без заливки на macOS 26. Разница почти не видна, оставлен выключенным.

## Раунд 3 (по вашему фидбеку)

### Исправления
- **Лаг при смене вкладок PR:** сворачивание заголовка анимировало высоту всего экрана вместе с diff-таблицей и WebView. Теперь переключение мгновенное.
- **Лаг скролла diff:**
  - панель файлов на каждом обновлении заново прогоняла CODEOWNERS-регэкспы по всем файлам ради чипа «Mine», теперь это кешируется;
  - тестовая сборка теперь release: debug рисовал diff в разы медленнее.
- **Merge спрашивает подтверждение.** Кнопка в шите открывает диалог «Merge #45 into main?» с методом, удалением ветки и предупреждением, если что-то блокирует. Слияние — только после второго подтверждения.

### Overview (новый раздел, ⌥⌘0)
- Первый пункт сайдбара; новые установки открываются на нём.
- Приветствие по времени суток и имя (засечки), сводка дня справа.
- Большая карточка «N reviews waiting for you» с первыми 5 PR, клик открывает PR. Если ничего нет — «Calm waters» с рисующимся логотипом.
- Сетка 4×2:
  - My pull requests, Ready to merge, Failing checks, Changes requested;
  - Assigned, Mentioned, Reviewed by me, Unread inbox.

  Числа анимируются. Клик открывает нужный список, для Ready/Failing/Changes — уже с фильтром.
- Карточка Agents: сколько работает или ждёт вас, кнопка «Open Agents» / «New session».
- «Recently opened»: последние PR чипами.

### Сайдбар
- Сверху без заголовка: **Overview, Notifications, Agents**.
- Группа Issues сворачивается.
- Внизу вместо пустоты — живая карточка **«Today»**: сколько ревью ждёт, работающие агенты, непрочитанные уведомления. Клик открывает Overview.

### Онбординг (Welcome Tour)
- Показывается один раз после входа, всем, включая текущих пользователей. Повторить: Help → Welcome Tour.
- Ночное небо со звёздами, волны, кораблик плывёт по страницам, небо меняет цвет — как в iOS.
- 5 страниц с живыми сценами:
  1. Welcome — рисующийся логотип.
  2. Overview — плитки с растущими числами.
  3. Клавиши — keycaps появляются по очереди.
  4. Merge — чек-лист отмечается, потом «Merged».
  5. Agents — лог агента.
- «Set sail» открывает Overview. Skip / Esc, стрелки ← →, Enter.

### Agents / чат
- Индикатор «Working…» — капсула с CA-лоадером и временем «1m 12s». Покадровый лоадер раньше перерисовывал ленту чата.
- Композер: обводка и мягкая тень.
- Пустое состояние «Agents on deck»: рисующийся логотип, волны, карточки проектов 2×3, подсказки ⌘N / ⇧⌘K.

## Онбординг: больше анимации
- Страницы перелистываются с учётом направления и размытием.
- За кораблём двойной светящийся след: фиолетовая и голубая ветки, как в логотипе.
- Падающие звёзды и лунные блики на воде.
- Сцена парит и наклоняется за курсором.
- «Set sail» пульсирует свечением, при отплытии звёзды растягиваются в штрихи.

## Фаза 3 (начало)
- **Diff: подсветка изменённой части строки.** Пары удалённая/добавленная строка внутри hunk; выделяется только отличающийся кусок (в unified и split). Есть тесты.
- **Checks:**
  - сверху сводка-чипы и «Required x/y»;
  - проверки сгруппированы по workflow, группы с ошибками раскрыты и идут первыми, успешные свёрнуты;
  - пометка «Required» у обязательных.
- **Очередь:**
  - коралловая точка «новая активность» на строках PR, обновлённых после того, как вы их открывали;
  - Snooze в контекстном меню: на час / до завтра 9:00 / до понедельника, с Undo;
  - отложенные PR внизу в свёрнутой секции «Snoozed», «Wake Up» возвращает;
  - «Mark as Seen».

## Что проверить руками
0. Онбординг при первом запуске, затем Overview и карточка «Today» в сайдбаре.
1. Открыть PR → кнопка обновления одна, заголовок окна = название PR.
2. Вкладка Files → плашка свернулась, панель файлов тянется, ⌥T, «Mine».
3. ⌘K на открытом PR → секция «This pull request».
4. Меню Pull Request → пункты активны на открытом PR.
5. Список: меню сортировки → Density → Compact / Standard; j/k.
6. Уведомления: наведение → ✓, E, Undo в тосте.
7. Шит Merge на чистом PR и на PR с блокерами (кнопки по таблице выше).
8. Approve / Merge → тост с действием (это меняет данные на GitHub).
9. Тёмная тема, Settings → Accessibility → Increase Contrast / Reduce Transparency.
